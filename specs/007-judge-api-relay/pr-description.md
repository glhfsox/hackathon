Judges previously needed private OpenAI and TypeSafe keys to run the project. This adds a Terraform-managed public provider relay with Secret Manager credentials and persistent Firestore quotas, plus an editable judge policy and Compose override. Judges run the control layer and dashboard locally with both provider keys blank. Direct-provider defaults remain supported; explicit `jev.api_key_env: null` enables relay transport.

The relay runs in `hackyeah-2026-510606`, `europe-west1`, with 700 lifetime provider calls, 60/minute, 32 KiB bodies, 2,048 OpenAI output tokens, and expiry October 5 at 23:59 Europe/Warsaw. Secret values are uploaded through stdin and never enter Terraform state. Public usage is bounded by requests/bytes/tokens, not an exact dollar cap; GCP request/storage costs remain possible.
